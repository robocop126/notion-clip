## Git Commit Message Rules (Strict)

1. **English only** - No Chinese characters allowed. Violations will be rejected.
2. Use **Conventional Commits** format: `<type>(<scope>): <description>`
3. Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`
4. Description: imperative mood, lowercase, no period at end
5. Examples:
   - `feat(auth): add login with OAuth2`
   - `fix(ui): resolve button hover state`
   - `docs(readme): update installation guide`
